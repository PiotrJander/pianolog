pianolog MIDI tester

Plays tunes and edge-case sequences into a MIDI output of this computer, to exercise the recorder without a piano. Needs Chrome, Edge or Firefox (Safari has no Web MIDI).

Getting the MIDI to the recorder

A laptop cannot be plugged straight into the recorder: both ends are USB hosts. Use any MIDI output this computer has, and a path to the recorder's Type-A port, for example:

two cheap USB-MIDI interface cables joined by a 5-pin DIN coupler (laptop → OUT plug → coupler → IN plug → recorder), or the piano itself acting as a bridge if it has MIDI IN and forwards it (most don't). Pick the port below; Also play here lets you hear what is being sent.

Output

Edge cases

Each test sends its sequence once. Compare the recorder's web page with the expected result; the note count appears in the take's file name (_0123n). Wait for the previous take to close (gap_s of silence) before starting the next test, unless the test says otherwise.
