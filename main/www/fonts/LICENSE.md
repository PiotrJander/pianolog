# Fonts

Latin subsets of two variable fonts, as served by Google Fonts, both under the
[SIL Open Font License 1.1](https://openfontlicense.org):

* `cormorant*.woff2`: Cormorant Garamond, Copyright 2015 The Cormorant Project Authors
  (github.com/CatharsisFonts/Cormorant)
* `garamond*.woff2`: EB Garamond, Copyright 2017 The EB Garamond Project Authors
  (github.com/octaviopardo/EBGaramond12)

They are embedded in the firmware so the web page looks the same without internet access.
